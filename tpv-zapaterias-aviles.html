¿Funciona el TPV durante cortes de luz?

El sistema requiere electricidad para funcionar, como cualquier equipo informático. Durante cortes de luz, ningún TPV operará. Para estos casos, recomiendo tener baterías auxiliares o sistemas de alimentación ininterrumpida que permitan trabajar temporalmente.

¿Puedo usar el sistema en varias cajas?

La licencia estándar cubre una única terminal. Si necesita múltiples puntos de venta, deberá adquirir licencias adicionales. Cada caja funciona independientemente y luego sincroniza datos cuando hay conexión disponible entre ellas.

¿Qué pasa cuando vuelve internet?

El sistema detecta automáticamente la reconexión y sincroniza todos los datos almacenados localmente. Las ventas, actualizaciones de stock y cambios realizados offline se integran sin pérdida de información. Todo ocurre en segundo plano sin intervención manual.
